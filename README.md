# Blog API Backend

Backend project with user and blog controllers, Passport configuration, authentication middleware and uploads.

## Project structure

`server/controllers/`, `server/models/`, `server/routes/`, `server/middlewares/`, `server/config/`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/blog_project---backend.git
cd blog_project---backend
```

Enter `server`, run `npm ci`, configure database and authentication locally and start using the package scripts.

## Security configuration

An environment file is currently tracked. Treat any real credentials in it as potentially exposed, rotate them, and migrate secrets to ignored local environment files. Do not publish secret values.
